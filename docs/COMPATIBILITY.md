# Game compatibility / 遊戲相容性

Whether a game shows PlayStation prompts depends on the game, not only on TSCC_WASD: it must
support a DualShock 4 natively or through Steam Input. This list collects real results.
Add yours with the [Game compatibility issue template](https://github.com/ynyrworks/TSCC_WASD/issues/new?template=game_compatibility.yml).

遊戲能否顯示 PS 圖示取決於遊戲本身：遊戲必須原生支援 DS4，或透過 Steam Input 支援。
這裡整理實際測試結果，歡迎用[遊戲相容性回報範本](https://github.com/ynyrworks/TSCC_WASD/issues/new?template=game_compatibility.yml)補充。
