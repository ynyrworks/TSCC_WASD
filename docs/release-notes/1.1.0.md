# TSCC_WASD 1.1.0

## 繁體中文

TSCC_WASD 1.1.0 換上全新介面，並讓每一種手把都能校準搖桿。1.0 的功能和承諾範圍都不變，改的是東西放在哪裡。

**完整教學：[使用手冊](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.zh-TW.md)**（English: [manual](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.md)）

### 新功能

- **新主視窗**：左側導覽，分成首頁、設定檔、程式設定、關於與說明四頁，跟著 Windows 的淺色／深色主題。原本的「關於」視窗併進「關於與說明」頁。
- **首頁**：顯示使用中的手把、連線方式、電量、即時按鍵、遊戲看到的手把、設定檔和三個常用開關。
- **設定檔**：獨立一頁，修改後自動儲存。
- **首次使用導覽**：指著真正的按鈕說明，可以在「關於與說明」重看；每個控制項旁都有「**?**」中英文說明。
- **所有手把都能校準搖桿**：Xbox、DualShock 4、DualSense、第一代 Switch Pro、NS2 Pro（USB 或藍牙）。從設定檔頁或首頁手把卡片開啟，需要先開始映射。能分辨個別手把時存成這支手把的校準，否則存成這個型號。取消會保留原本的校準，「清除校準」會刪除。
- **電量**：首頁顯示手把電量和是否充電；輸出 DualShock 4 時，遊戲看到的虛擬手把也回報同樣的電量。
- 手冊寫明**不需要 Steam**：虛擬手把是系統層級的裝置，任何平台或直接執行的遊戲都看得到。

### 更新方式

從 1.0.0 在「關於與說明」按「檢查更新」即可，程式會先核對 SHA-256 才安裝，設定檔會保留。

手動下載：

1. 下載 `TSCC_WASD-1.1.0-win-x64.zip` 與 `TSCC_WASD-1.1.0-win-x64.zip.sha256`。
2. PowerShell：`Get-FileHash .\TSCC_WASD-1.1.0-win-x64.zip -Algorithm SHA256`，結果要和 `.sha256` 檔一致。
3. 解壓縮後執行 `TSCC_WASD.exe`。

**本版沒有數位簽章**。SmartScreen 可能警告，請按「其他資訊 → 仍要執行」，但只限於雜湊值相符的 ZIP。原因見[程式碼簽章政策](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/CODE-SIGNING-POLICY.md)。

### 已知限制

- 同一支手把同時存有「這支手把」和「這個型號」兩份校準時，「清除校準」要按兩次才會都清掉。
- Steam 把虛擬 DS4 當成 USB 手把，可能不顯示電量；程式首頁的電量顯示不受影響。
- 1.0 的限制仍然適用：不支援任意按鍵重排、巨集、觸控板滑動、鍵鼠輸入、DualSense 輸出與疊圖；PS 圖示要遊戲支援 DS4 或透過 Steam Input；NS2 Pro 的 C 鍵與背面 GL/GR 尚未映射、ZL/ZR 為數位；第一代 Switch Pro 沒有震動；部分反作弊會拒絕虛擬手把；ViGEmBus 上游已停止維護。

## English

TSCC_WASD 1.1.0 brings a new interface and stick calibration for every controller. What 1.0 does and promises is unchanged;
what changed is where things are.

**Full guide: the [user manual](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.md)** (中文：[使用手冊](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.zh-TW.md))

### What's new

- **New main window** with a navigation pane and four pages: Home, Profiles, App settings and About & help. It follows the Windows light or dark theme. The About window is now the About & help page.
- **Home** shows the controller in use, its connection, battery and live input, the controller games see, the profile and three everyday switches.
- **Profiles** have their own page and save automatically.
- **First-run tour** pointing at the real controls; replay it from About & help. Every control has a **?** with a short explanation in both languages.
- **Stick calibration for every controller:** Xbox, DualShock 4, DualSense, the original Switch Pro and the NS2 Pro over USB or Bluetooth. Open it from the Profiles page or the Home controller card; mapping must be running. It is saved per controller when the controller can be told apart, otherwise per model. Cancel keeps the earlier calibration; **Clear calibration** removes it.
- **Battery:** Home shows the battery level and charging; with DualShock 4 output the virtual controller reports the same battery to games.
- The manual says plainly that **Steam is not required**: the virtual controller is a system-wide device that any launcher or game can see.

### How to update

From 1.0.0, click *Check for updates* on About & help. The app checks the SHA-256 before installing and keeps your profiles.

Manual download:

1. Download `TSCC_WASD-1.1.0-win-x64.zip` and `TSCC_WASD-1.1.0-win-x64.zip.sha256`.
2. In PowerShell run `Get-FileHash .\TSCC_WASD-1.1.0-win-x64.zip -Algorithm SHA256`; it must match the `.sha256` file.
3. Extract and run `TSCC_WASD.exe`.

**This release is not code-signed.** SmartScreen may warn: choose *More info → Run anyway*, but only for a ZIP whose hash matched. See the [code signing policy](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/CODE-SIGNING-POLICY.md).

### Known limits

- When a controller has both a per-controller and a per-model calibration, *Clear calibration* has to be clicked twice to remove both.
- Steam lists the virtual DS4 as a USB controller and may not show its battery; the battery on the Home page is not affected.
- The 1.0 limits still apply: no arbitrary remapping, macros, touchpad surface, keyboard/mouse input, DualSense output or overlays; PS prompts need DS4 support in the game or Steam Input; the NS2 Pro's C and rear GL/GR buttons are not mapped and ZL/ZR are digital; the original Switch Pro has no rumble; some anti-cheat rejects virtual controllers; ViGEmBus is no longer maintained upstream.
