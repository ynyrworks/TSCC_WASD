# TSCC_WASD 1.0.0

## 繁體中文

TSCC_WASD 1.0.0 是第一個正式版：免費開源的 Windows 工具，讓遊戲把你的 Xbox 或 Nintendo Switch 2 Pro 手把當成
PlayStation DualShock 4，顯示 PS 按鍵圖示；也可以輸出虛擬 Xbox 360 手把。不用訂閱、沒有遙測。

**完整教學：[使用手冊](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.zh-TW.md)**（English: [manual](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.md)）

### 1.0 承諾的範圍

- Xbox 手把：USB、藍牙。
- Nintendo Switch 2 Pro（NS2 Pro）：USB。
- 輸出成 DualShock 4 或 Xbox 360。

### 實驗性（可能可以用，但不做保證）

DualShock 4、DualSense、第一代 Switch Pro、NS2 Pro 藍牙（按住 Sync 連線）、隱藏第三方 XInput 手把。
實際測過什麼見[驗證紀錄](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/VALIDATION.md)。

### 0.9.x 以來的重點

- 一鍵隱藏實體手把（HidHide），停止後完整還原；Steam 先開時用「自動重新連接」，不必重啟 Steam。
- 程式內更新（0.9.1 起）：先詢問、核對 SHA-256 才安裝。
- 依遊戲程序名稱自動切換設定檔；圓形搖桿死區。
- NS2 Pro 藍牙（實驗性）、第一代 Switch Pro 使用手把內建的搖桿校準。
- 手把測試視窗與報告匯出。
- 修正 NS2 Pro USB 在隱藏手把時被 HidHide 拒絕存取。
- 新增完整的中英文使用手冊。

### 如何驗證下載

1. 下載 `TSCC_WASD-1.0.0-win-x64.zip` 與 `TSCC_WASD-1.0.0-win-x64.zip.sha256`。
2. PowerShell：`Get-FileHash .\TSCC_WASD-1.0.0-win-x64.zip -Algorithm SHA256`，結果要和 `.sha256` 檔一致。
3. 解壓縮後執行 `TSCC_WASD.exe`。

**本版沒有數位簽章**（簽章不屬於 1.0）。SmartScreen 可能警告，請按「其他資訊 → 仍要執行」，但只限於雜湊值相符的 ZIP。
原因與政策見[程式碼簽章政策](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/CODE-SIGNING-POLICY.md)。

### 已知限制

- 不支援任意按鍵重排、巨集、觸控板滑動、鍵鼠輸入、DualSense 輸出與疊圖。
- PS 圖示取決於遊戲：遊戲要原生支援 DS4，或透過 Steam Input。
- NS2 Pro 的 C 鍵與背面 GL/GR 尚未映射；ZL/ZR 為數位輸出。
- NS2 Pro 藍牙每次都要按住 Sync，回報頻率約 67 次／秒，搖桿校準精靈只支援 USB。
- 第一代 Switch Pro 尚不支援震動。
- 部分反作弊（例如 EA Javelin）會拒絕虛擬手把。
- ViGEmBus 上游已停止維護，目前仍可使用。
- Windows 10 需要 2004 版以上。

## English

TSCC_WASD 1.0.0 is the first official release: a free, open-source Windows tool that makes games see your Xbox or Nintendo
Switch 2 Pro controller as a PlayStation DualShock 4, so they show PS prompts. It can also output a virtual Xbox 360 controller.
No subscription, no telemetry.

**Full guide: the [user manual](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.md)** (中文：[使用手冊](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/MANUAL.zh-TW.md))

### What 1.0 promises

- Xbox controllers: USB and Bluetooth.
- Nintendo Switch 2 Pro (NS2 Pro): USB.
- Output as a DualShock 4 or an Xbox 360 controller.

### Experimental (may work, no promise)

DualShock 4, DualSense, the original Switch Pro, the NS2 Pro over Bluetooth (hold Sync to connect) and hiding third-party XInput
controllers. What was actually tested is in the [validation record](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/VALIDATION.md).

### Highlights since 0.9.x

- One-click hiding of the real controller (HidHide), fully restored on stop; automatic reconnect when Steam started first, so no Steam restart.
- In-app updates (since 0.9.1): it asks first and checks the SHA-256 before installing.
- Per-game profile switching by process name; round stick dead zone.
- NS2 Pro over Bluetooth (experimental); original Switch Pro uses the controller's own stick calibration.
- Controller test window and report export.
- Fixed: an NS2 Pro over USB could stay unusable while hiding because HidHide refused access.
- A full user manual in English and Chinese.

### How to verify the download

1. Download `TSCC_WASD-1.0.0-win-x64.zip` and `TSCC_WASD-1.0.0-win-x64.zip.sha256`.
2. In PowerShell run `Get-FileHash .\TSCC_WASD-1.0.0-win-x64.zip -Algorithm SHA256`; it must match the `.sha256` file.
3. Extract and run `TSCC_WASD.exe`.

**This release is not code-signed** (signing is not part of 1.0). SmartScreen may warn: choose *More info → Run anyway*, but only for a ZIP
whose hash matched. The reason and the policy are in the
[code signing policy](https://github.com/ynyrworks/TSCC_WASD/blob/main/docs/CODE-SIGNING-POLICY.md).

### Known limits

- No arbitrary remapping, macros, touchpad surface, keyboard/mouse input, DualSense output or overlays.
- PS prompts depend on the game: it must support DS4 natively or through Steam Input.
- The NS2 Pro's C and rear GL/GR buttons are not mapped; ZL/ZR are digital.
- NS2 Pro over Bluetooth needs Sync held every time, runs at about 67 reports/s, and the calibration wizard is USB only.
- The original Switch Pro has no rumble yet.
- Some anti-cheat (for example EA Javelin) rejects virtual controllers.
- ViGEmBus is no longer maintained upstream; it still works.
- Windows 10 needs version 2004 or later.
