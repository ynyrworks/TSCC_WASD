# TSCC_WASD 1.1.2

## 繁體中文

映射中才連上的藍牙手把會直接被接手，不必重開映射。

- 修正：Switch Pro、DualShock 4 或 DualSense 在映射進行中才連上（或關機再開），會一直顯示「存取被拒」，要停止再啟動映射才能用。原因是 HidHide 已經把它藏起來了。現在這些手把也有 NS2 Pro 原本就有的補救：程式先重新向 HidHide 註冊自己，不行就只把那一支手把短暫取消隱藏、打開後再藏回去。用這個方式打開的 Switch Pro 也會拿到寫入通道，因此能切到完整模式，不會停在「簡易模式」。
- 修正：藍牙 Switch Pro、DualShock 4、DualSense 的搖桿校準在重新配對後仍會保留。校準改用手把的藍牙位址儲存，不再用每次配對都會變的 Windows 裝置代號；舊版本存的校準會在手把連上時自動找到並搬到新位置。

從 1.1.x 或 1.0.0 在「關於與說明」按「檢查更新」即可，程式會先核對 SHA-256 才安裝。手動下載請用 `.sha256` 檔核對 `TSCC_WASD-1.1.2-win-x64.zip`。本版沒有數位簽章。

---

## English

Bluetooth controllers that connect while mapping is on are picked up without restarting mapping.

- Fixed: a Switch Pro, DualShock 4 or DualSense that connected (or was switched off and on) while mapping was running stayed at "access denied" until mapping was stopped and started again, because HidHide was already hiding it. These controllers now get the recovery the NS2 Pro already had: TSCC_WASD registers itself with HidHide again and, if that is not enough, unhides that one controller for a moment to open it. A Switch Pro opened this way also gets its write handle, so it switches to full reports instead of staying in simple mode.
- Fixed: a stick calibration of a Bluetooth Switch Pro, DualShock 4 or DualSense is kept when the controller is paired again. It is saved under the controller's Bluetooth address instead of a Windows id that changes on every pairing; calibrations saved by earlier versions are found and moved to the new key when the controller connects.

Update from 1.1.x or 1.0.0 with *Check for updates* on About & help; the app checks the SHA-256 before installing. For a manual download, check `TSCC_WASD-1.1.2-win-x64.zip` against its `.sha256` file. This release is not code-signed.
