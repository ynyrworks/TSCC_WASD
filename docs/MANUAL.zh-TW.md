## 這個程式做什麼、不做什麼

很多遊戲只認 PlayStation 手把的按鍵圖示（✕ ○ □ △），或只認 Xbox 手把。TSCC_WASD 在 Windows 上建立一支**虛擬手把**，
讀取你真正的手把，再把輸入轉給虛擬手把，遊戲看到的就是你指定的那一種：

- 輸出 **DualShock 4**：遊戲顯示 PS 圖示（遊戲本身要支援 DS4，或透過 Steam Input 支援）。
- 輸出 **Xbox 360**：相容性最好，也可以讓 PlayStation 或任天堂手把顯示 Xbox 圖示。

它用兩個免費的驅動程式完成工作：**ViGEmBus**（建立虛擬手把）與 **HidHide**（把真正的手把藏起來，遊戲才不會同時看到兩支）。
這兩個都是 Nefarius 的專案，TSCC_WASD 會幫你安裝，也會在映射時自動設定 HidHide。

**它不做的事：** 任意按鍵重排、巨集、觸控板滑動、鍵盤滑鼠輸入、DualSense 輸出、遊戲疊圖。
PS 圖示是否出現仍取決於遊戲：只內建 Xbox 圖示的遊戲，不論你用什麼手把都會顯示 Xbox 圖示。
沒有遙測，沒有背景服務；只有你按「檢查更新」或「安裝驅動程式」，或開啟了「開啟程式時檢查更新」時才會連到 GitHub。

**承諾支援的範圍：** Xbox 手把（USB、藍牙）和 USB 連接的 Nintendo Switch 2 Pro（NS2 Pro）。
DualShock 4、DualSense、第一代 Switch Pro、NS2 Pro 藍牙，以及隱藏第三方 XInput 手把都是**實驗性**：可能可以用，但不做保證。
詳見[各種手把](#各種手把)。

## 系統需求

- Windows 10（2004 版以上）或 Windows 11，x64。Windows 11 是主要測試平台。
- 不需要另外安裝 .NET；下載的 ZIP 已包含。
- 安裝 ViGEmBus 與 HidHide 時需要管理員權限，可能要重新開機一次。
- NS2 Pro 藍牙需要電腦內建（或相容）的藍牙 LE 介面卡。

## 下載與驗證

1. 到 [Releases](https://github.com/ynyrworks/TSCC_WASD/releases) 下載最新版的 `TSCC_WASD-<版本>-win-x64.zip`，
   同一頁還有一個 `.sha256` 檔。

2. **核對 SHA-256。** 在 ZIP 所在的資料夾開啟 PowerShell，執行：

   ```powershell
   Get-FileHash .\TSCC_WASD-<版本>-win-x64.zip -Algorithm SHA256
   ```

   輸出的 `Hash` 要和 `.sha256` 檔裡的那串字（不分大小寫）完全一致。不一致就不要執行，重新下載。

3. 在 ZIP 上按右鍵「全部解壓縮」，**解壓到一個資料夾**再執行 `TSCC_WASD.exe`（不要直接在 ZIP 裡面執行）。
4. **SmartScreen 警告：** 第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」。請按「**其他資訊**」，再按「**仍要執行**」。

   **為什麼會這樣？** TSCC_WASD **尚未簽章**（程式在「關於與說明」頁以「**尚未簽章**」標示）。程式碼簽章憑證要付費，也要經過審核；
   這是個免費的個人專案，目前沒有取得。SmartScreen 對沒有簽章又很少人下載的程式一律會警告，不代表程式有問題，
   也不代表它沒問題，所以才需要上一步的 SHA-256 核對：只有 SHA-256 和 Release 頁面相符的 ZIP 才按「仍要執行」。
   詳見[程式碼簽章政策](CODE-SIGNING-POLICY.md)與[簽章說明](SIGNING.md)。

只有第一次需要手動下載，之後的新版可以[在程式內更新](#在程式內更新)。

## 首頁

首頁顯示現在的狀況，並放著每天會用到的控制項。

- **狀態卡。** 第一行說明程式正在做什麼：「已停止：實體手把可見」、「映射中：遊戲看到虛擬 DualShock 4」（或 Xbox 360），
  或「已暫停：遊戲看到放開所有按鍵的虛擬…」。下面是使用中的手把（名稱與連線方式：USB 或藍牙），映射中還會即時顯示你按下的按鍵。
  找不到手把時，旁邊的「**?**」會告訴你該怎麼做。
- **開始映射／停止映射。** 大按鈕會建立虛擬手把，並把實體手把的輸入送給它；請先開始映射、再開遊戲。缺少驅動程式時會先詢問是否安裝。
  映射中此鈕會變成「**停止映射**」。
- **▾（更多動作）。** 旁邊的選單有「**暫停**」（暫停中會變成「**繼續**」）、「**完全釋放（停止）**」與「**安裝驅動程式**」。
  暫停適合短暫休息：遊戲看到放開所有按鍵的虛擬手把，實體手把仍然隱藏，所以繼續時不必處理 Steam。
  「完全釋放（停止）」會讓虛擬手把消失、實體手把恢復可見，HidHide 也還原成映射之前的樣子。關閉 TSCC_WASD 也一樣；
  就算程式被強制結束，下次開啟時也會自動還原。
- **遊戲看到的手把。** 顯示目前的輸出（DualShock 4：「PS 圖示、觸控板、體感」；Xbox 360：「Xbox 圖示，相容性最好」）。
  要更改請到「設定檔」頁的「輸出成」；映射中切換立即生效，但遊戲可能要重開才會重新抓到手把。
- **設定檔。** 下拉選單，內容與「設定檔」頁相同。當選到的設定檔設了遊戲程序，會顯示「遊戲在前景時自動切換」
  （見[依遊戲自動切換](#依遊戲自動切換)）。
- **Steam。** 「**重新啟動 Steam**」（映射中才能按）讓 Steam 只看到虛擬手把。見 [Steam](#steam-與重新啟動)。
- **三個開關**（套用在目前的設定檔）：「**隱藏實體手把（需 HidHide）**」「**把遊戲震動轉給實體手把**」「**對調 A/B 與 X/Y**」。
  與「設定檔」頁是同一組選項。
- **頁尾。** 說明 HidHide 是否正在隱藏實體手把，並顯示驅動程式狀態。下載更新時會出現進度列與「**取消**」。

## 設定檔頁

一個設定檔就是一組輸出選項，可以建立很多個（例如「PS 圖示」「Xbox 圖示」）。在清單中點選要編輯的設定檔，修改會自動儲存。

頁面上方：「**新增**」新增一個設定檔（再改名、調整選項）。「**⋯**」選單（更多）有：

| 選單項目 | 作用 |
| --- | --- |
| **移除** | 移除目前選取的設定檔 |
| **複製** | 複製目前的設定檔，作為另一組設定的起點 |
| **匯入** | 從檔案匯入設定檔，格式見[設定檔格式](PROFILES.md) |
| **匯出全部** | 把全部設定檔匯出成一個檔案，可備份或分享 |
| **從磁碟重新載入** | 先儲存待寫入的修改，再從 `profiles.json` 重新讀取 |
| **開啟設定資料夾** | 開啟 `%APPDATA%\TSCC_WASD` |

設定檔損壞時程式不會覆寫它，並停用編輯；用「開啟設定資料夾」修復檔案或還原 `profiles.json.bak` 後，按「從磁碟重新載入」。

選取的設定檔有這些選項：

| 選項 | 說明 |
| --- | --- |
| 設定檔名稱、說明 | 名稱最多 100 字；說明是給自己看的備註 |
| 遊戲程序 | 見[依遊戲自動切換](#依遊戲自動切換)。「**挑選…**」會開啟[從執行中的程式挑選](#從執行中的程式挑選) |
| 輸入手把 | 預設「自動偵測（所有支援的手把，建議）」：同時監看所有支援的手把，你按哪一支就用哪一支，閒置的手把不會搶走控制權。也可以指定只用某一種：「只用 Xbox／XInput」「只用 Nintendo Switch 2 Pro（USB）」「只用 Nintendo Switch 2 Pro（藍牙，實驗性，按住 Sync 連線）」「只用 DualShock 4／DualSense（實驗性）」「只用 Switch Pro 手把（第一代，實驗性）」 |
| 輸出成 | 「DualShock 4（PS 按鍵圖示）」：PS 圖示、PS 鍵、觸控板、體感；「Xbox 360（Xbox 按鍵圖示）」：相容性最好。映射中切換會立即生效，但遊戲可能需要重開 |
| 對調 A/B 與 X/Y | 任天堂習慣：右邊的鍵是確認。勾選後右側鍵送出 ✕／Xbox A，下方鍵送出 ○／Xbox B。NS2 Pro 會改成依按鍵上的字母對應，而不是依位置 |
| 隱藏實體手把（需 HidHide） | 遊戲只看得到虛擬手把。預設開啟 |
| 把遊戲震動轉給實體手把 | 遊戲送給虛擬手把的震動轉給 Xbox、NS2 Pro、DualShock 4、DualSense（第一代 Switch Pro 尚不支援震動；NS2 Pro 震動需要 USB） |
| Xbox 的 View（Back）鍵當作觸控板按下 | PS 遊戲常用觸控板開地圖或選單。取消勾選則 View 鍵送出 Share。NS2 Pro 不受影響（－鍵是 Share、截圖鍵是觸控板） |
| 搖桿死區（0–0.95） | 圓形死區：把搖桿當成一個點，看它離中心多遠，所以斜向不會被拉向軸線。預設 0.08。搖桿放著會飄時調大 |
| 目標輪詢頻率（30–500 Hz） | 預設 125。這是目標值，不是即時保證；一般不必更動 |

頁面下方有兩個入口會開啟子視窗：「**校準搖桿**」（見[搖桿校準](#搖桿校準)）與「**手把測試與報告匯出**」（見[手把測試](#手把測試)）。

按鍵對應是固定的：A/B/X/Y 對應 ✕／○／□／△，Back/Start 對應 Share/Options，LB/RB 對應 L1/R1，搖桿按下對應 L3/R3；
Xbox 的 Guide 鍵與 NS2 的 Home 鍵當作 PS 鍵，NS2 的截圖鍵當作觸控板按下。NS2 Pro 的 C 鍵與背面 GL/GR 尚未映射。

**上傳到 GitHub 前請先打開看過**；程式不會自動上傳任何東西。「**關閉**」關閉視窗。

## 第一次設定

1. **安裝驅動程式。** ZIP 裡的 `drivers` 資料夾附有 **ViGEmBus**（必要）與 **HidHide**（強烈建議）的官方安裝程式。
   第一次開啟 TSCC_WASD，如果偵測到缺少驅動，會詢問是否安裝：按「**是**」。程式會先核對安裝檔的 SHA-256，
   再依序執行安裝程式（Windows 會要求管理員權限）。如果它要求重新開機，**請先重開機**，再開啟 TSCC_WASD。
   你**不需要自己設定 HidHide**，映射時程式會處理。選了「否」也沒關係：「安裝驅動程式」（首頁的 ▾ 選單，或「程式設定」頁）
   隨時可以再裝。如果 `drivers` 資料夾裡的安裝檔不見了，程式才會從 GitHub 下載官方安裝程式。
2. 跟著[新手導覽](#首次啟動的新手導覽)看一遍，或直接略過。
3. 接上手把（Xbox 手把、USB 的 NS2 Pro；其他手把見[各種手把](#各種手把)）。
4. 到「**設定檔**」頁，「**輸入手把**」保持「自動偵測」；「**輸出成**」選「DualShock 4（PS 按鍵圖示）」
   （想要 Xbox 圖示就選 Xbox 360）。確認「**隱藏實體手把（需 HidHide）**」是開啟的。
5. 回到「**首頁**」，確認「設定檔」卡片，按「**開始映射**」。
6. 如果程式說 Steam 已經在執行，見下一節。
7. 狀態出現「映射中：遊戲看到虛擬 DualShock 4」之後，**再開遊戲**。順序很重要：HidHide 只能阻止程式「打開」手把，
   不能把已經被打開的手把搶回來，所以遊戲若已經開著，請在映射啟動後重開遊戲。

短暫休息請用 ▾ 選單的「**暫停**」；要結束映射按「**完全釋放（停止）**」或「**停止映射**」。

> ViGEmBus 上游已停止維護（[公告](https://docs.nefarius.at/projects/ViGEm/End-of-Life/)）。它目前仍可正常運作，TSCC_WASD 也還在使用它。

## Steam 與重新啟動

Steam 的 Steam Input 會「打開」你的手把，並把它轉給 Steam 遊戲。如果 Steam 比映射先開，HidHide 就搶不回來，
結果是遊戲同時看到實體手把和虛擬手把，圖示在 Xbox 與 PS 之間交替。解法有三種，由方便到備案：

1. **自動重新連接（建議，USB 手把）：** 開始映射時若 Steam 已在執行，程式會詢問是否設定「自動重新連接」。
   選「是」，確認一次 Windows 管理員提示，之後就不會再問（也可以在「程式設定」頁的「自動重新連接」按「**設定**」）。
   它會讓 USB 手把斷電重新連接一兩秒，手把回來時已經對 Steam 隱藏。藍牙手把不能這樣處理，把手把關掉再開一次即可。
2. **重新啟動 Steam：** 選「否」，或按首頁的「**重新啟動 Steam**」（映射中才能按）。
3. **讓 Steam 永遠晚一步：** 見[系統匣與開機自動啟動](#系統匣與開機自動啟動)。

自動重新連接會把 TSCC_WASD 複製到 `%ProgramFiles%\TSCC_WASD\Helper`（只有管理員能修改），並建立一個只在需要時才執行的排程工作
`\TSCC_WASD\ReconnectControllers`。要移除，到「程式設定」頁的「自動重新連接」按「**移除**」。程式更新後需要重新按一次「設定」。

遊戲內的 Steam Input 設定請保持「預設／啟用」：有些遊戲（例如人中之龍 0 導演剪輯版）的 PS 圖示就是靠 Steam Input 決定的，停用後反而顯示 Xbox 圖示。
停止映射後，如果 Steam 在隱藏期間失去了手把，程式會重新連接它（沒設定自動重新連接時會詢問是否重啟 Steam）。
NS2 Pro 在較新的 Steam 上，停止後的自動重新連接可能不足以讓 Steam 重新認出手把；拔掉再插一次，或按「重新啟動 Steam」。

## 依遊戲自動切換

在「設定檔」頁的「**遊戲程序**」填入遊戲的程序名稱（例如 `game.exe`，不分大小寫，`.exe` 可省略），
或按「**挑選…**」從[執行中的程式](#從執行中的程式挑選)選。留空則不使用。

映射中：

- 遊戲來到前景時，套用這個設定檔；
- 你 Alt-Tab 離開時，設定檔不變；
- 遊戲結束後，切回原本的設定檔；
- 期間你在首頁手動選的設定檔優先；自動切換的結果不會存成你的設定檔；
- 如果切換造成輸出類型改變（DS4 與 Xbox 360 之間），程式會通知你：遊戲若沒抓到手把，請重開遊戲；
- 這個功能**不會自己開始映射**。

## 各種手把

在「輸入手把」選「自動偵測」時，所有支援的手把都會被一起監看。

### Xbox（穩定範圍）

- **USB：** 直接接上。已實機驗證 XInput 存取與 HidHide 隱藏。
- **藍牙：** 在 Windows「設定 → 藍牙與裝置」配對（按住手把頂端的配對鍵，直到燈號快速閃爍，再在 Windows 選它）。
  已實機驗證 HidHide 隱藏，以及透過 Steam Input 顯示 PS 圖示。
- Xbox 無線接收器上的手把也可以用；自動重新連接時，接收器會整個重新連接，上面所有手把都會重連。
- Guide 鍵當作 PS 鍵；View 鍵當作觸控板按下（可在設定檔改成 Share）。

### NS2 Pro：USB（穩定範圍）

1. 用 USB 線接上 NS2 Pro，輸入保持「自動偵測」（或選「只用 Nintendo Switch 2 Pro（USB）」），按「開始映射」。
2. 按鍵依實體位置對應：B→✕、A→○、Y→□、X→△；Home→PS 鍵、Capture→觸控板按下；－／＋→Share／Options。
3. ZL／ZR 是數位開關（0 或 255），不是類比扳機。陀螺儀與 HD 震動都支援。C 鍵與背面 GL/GR 尚未映射。
4. Steam 開著時，程式讀不到手把的原廠搖桿校準，會使用你自己的校準、已記住的原廠校準，或自動學習搖桿行程；
   建議做一次[搖桿校準](#搖桿校準)。
5. 一次只能接一支 NS2 Pro。

### NS2 Pro：藍牙（實驗性）

NS2 Pro 的藍牙是藍牙 LE，Windows 不會把它當成手把，所以 TSCC_WASD 自己連線，**不需要在 Windows 配對**，也不需要接收器。

1. 拔掉 USB 線。「輸入手把」選「自動偵測」或「只用 Nintendo Switch 2 Pro（藍牙…）」，按「開始映射」。
2. **按住手把頂端的 Sync 鍵**，直到燈號開始跑。約 1–2 秒後狀態會顯示「NS2 Pro（藍牙，…）」。
3. 手把關機或斷線後，**再按住一次 Sync** 才會重新連線。

已知限制：每次都要按住 Sync（因為不寫入配對資訊，手把仍記得 Switch 2 主機，回主機玩不需要任何動作）；
回報頻率約 67 次／秒（Windows 11），低於 USB；Windows 與 Steam 都看不到它，所以不需要隱藏；
搖桿校準目前只支援 USB（見[搖桿校準](#搖桿校準)），藍牙使用手把內的原廠校準，或你先前用 USB 存下的校準；
已實機測試輸入、校準、體感、震動與重新連線，但尚未在遊戲中實測。

### 第一代 Switch Pro（實驗性）

藍牙：按住手把頂端的小同步鍵直到燈號開始跑，在 Windows 藍牙設定配對。已實機測試藍牙：所有按鍵、使用手把內建校準的搖桿，以及 HidHide 隱藏。
**尚不支援震動。** USB 尚待實體手把測試。

### DualShock 4、DualSense（實驗性）

USB 或藍牙。藍牙配對：DualShock 4 按住 Share + PS 鍵，DualSense 按住 Create + PS 鍵，直到燈條快速閃爍，再在 Windows 藍牙設定選它。
陀螺儀會轉成 DS4 體感，震動會轉給手把。**尚待實體手把測試**，歡迎回報結果。

### 藍牙配對一直失敗或幾秒就斷線

如果手把在 Windows 配對後，燈號一直閃爍、幾秒鐘就斷線：到「設定 → 藍牙與裝置」**移除這個裝置**，讓手把進入配對模式，重新配對一次。
這通常是 Windows 的配對記錄有問題，和 TSCC_WASD 無關。（NS2 Pro 藍牙不走 Windows 配對，不適用這一段。）

## 搖桿校準

如果搖桿推到底卻像輕推（例如只能走不能跑），或放開時會飄移，請做一次校準。映射中也可以做，儲存後立即套用。Xbox、PlayStation、Switch Pro、NS2 Pro（USB 或藍牙）都能校準，需先開始映射。

1. 從「設定檔」頁的「**校準搖桿**」，或首頁手把卡片上的校準按鈕開啟精靈，視窗標題會寫出手把名稱，例如「校準 NS2 Pro 搖桿」。
2. **步驟 1／2：** 把手把放在桌上，不要碰兩支搖桿，按「下一步」。
3. **步驟 2／2：** 把兩支搖桿（「左搖桿」「右搖桿」）沿著邊緣各慢慢轉 3 圈，確實推到底。每個方向（上、下、左、右）的進度條都滿了，就按「儲存」。
   「取消」會關閉精靈，不儲存。
4. 校準存好後優先使用，不論 Steam 開不開。要放棄時，按「**清除校準**」，只會清掉這支手把（或這個型號）的校準，之後改用原廠校準或自動學習。

## 系統匣與開機自動啟動

TSCC_WASD 會在通知區域（系統匣）放一個圖示：**映射中有綠點**，暫停時有橘點。
滑鼠移上去會顯示狀態，連按兩下開啟視窗，右鍵選單有「顯示視窗」「開始映射」「暫停」「停止映射」「結束」。

在「程式設定」頁勾選「**最小化時縮到系統匣**」，最小化後視窗就收進系統匣。

**開機自動啟動（建議）：** 在「程式設定」頁把「登入 Windows 時」選成「登入時啟動…」的選項，
「自動開始映射時的 Steam」選「Steam 沒開就啟動」（或「已開啟就重啟，沒開就啟動 Steam」），
再到 Steam 設定關閉「電腦開機時執行 Steam」。登入後 TSCC_WASD 會先隱藏手把、在系統匣開始映射，然後才啟動 Steam，
Steam 就永遠看不到實體手把。登入後沒看到視窗是正常的：從系統匣圖示開啟。
萬一 Steam 還是先開了，「Steam 已開啟就重啟」會處理。

## 在程式內更新

在「關於與說明」頁按「**檢查更新**」（或在「程式設定」頁勾選「開啟程式時檢查更新」）。有新版本時：

1. 程式詢問是否下載；選「是」才會從 GitHub 下載該版本的 ZIP。按「取消」可中止下載。
2. 下載完會核對 SHA-256（發行版簽章後也會核對數位簽章）。核對失敗就不會安裝。
3. 再詢問是否現在安裝並重新啟動。若正在映射，會先停止映射並還原 HidHide 設定，再更新。
4. 更新後如果「自動重新連接」要重新設定，到「程式設定」頁的「自動重新連接」再按一次「設定」。

沒有你的同意，程式不會下載或安裝任何東西。更新程式只接受名稱為 `TSCC_WASD-<版本>-win-x64.zip`、且能核對 SHA-256 的發行版。
0.9.1 以前的舊版只會開啟下載頁，要先手動安裝新版一次。

## 疑難排解

| 狀況 | 處理 |
| --- | --- |
| 程式打不開 | 先把整個 ZIP 解壓縮再執行，不要在 ZIP 裡面直接執行 |
| SmartScreen 警告 | 見[下載與驗證](#下載與驗證)：只有 SHA-256 相符時才按「其他資訊 → 仍要執行」 |
| 連接驅動失敗 | 按「安裝驅動程式」（或執行 ZIP 裡 `drivers` 的安裝檔），依提示重新開機；登錄檔顯示已安裝不代表驅動正在運作 |
| 「安裝驅動程式」說雜湊不符 | `drivers` 裡的安裝檔被改過或損壞，請重新下載 ZIP |
| 一直顯示等待手把 | 確認手把已連接（NS2 Pro 走 USB，或藍牙時按住 Sync）；若曾手動設定 HidHide，檢查允許的程式路徑 |
| 「NS2 Pro USB 正被其他程式使用」或手把「使用中」 | 通常是 Steam（或別的程式）握著手把。開始映射後按「重新啟動 Steam」，或先完全結束 Steam 再開始映射；也要關閉 DS4Windows 這類其他映射工具 |
| 「HidHide 拒絕存取手把」 | 程式已經自動重新登記並短暫取消隱藏再重試。停止映射，拔掉手把再插回去，重新開始映射；仍然不行，就用 `drivers` 裡的安裝檔更新 HidHide，並附上日誌回報 |
| 圖示在 Xbox 與 PS 之間跳動、按鍵重複 | 安裝 HidHide，保持「隱藏實體手把（需 HidHide）」開啟；**先映射再開遊戲**；Steam 若先開了就重新連接或重啟 Steam；停止其他映射工具 |
| 自動重新連接後 Steam 還是看到實體手把 | 藍牙手把不能被重新連接：把手把關掉再開。USB 集線器不支援埠斷電時，重插線或按「重新啟動 Steam」 |
| 自動重新連接要重新設定 | 程式更新後，輔助程式的版本必須和執行中的版本一致。到「程式設定」頁的「自動重新連接」再按一次「設定」 |
| 停止後 Steam 沒有重新看到手把 | 拔掉再插回去一次，或按「重新啟動 Steam」 |
| 藍牙手把配對後幾秒就斷線、燈一直閃 | 到 Windows 藍牙設定移除裝置，重新配對（見[上面](#藍牙配對一直失敗或幾秒就斷線)） |
| 沒有震動 | 確認勾選「把遊戲震動轉給實體手把」；遊戲必須對 DS4 送出震動；NS2 Pro 震動需要 USB；第一代 Switch Pro 尚不支援震動 |
| 還是看到 Xbox 圖示 | 遊戲必須原生支援 DS4 或透過 Steam Input；檢查 Steam Input 設定；或確認「輸出成」不是 Xbox 360 |
| 想要 Xbox 圖示 | 在「設定檔」頁把「輸出成」選 Xbox 360，映射中切換就會套用 |
| 遊戲拒絕啟動或把你踢出（程式提示 EA Javelin） | 部分反作弊會拒絕虛擬手把：按「完全釋放（停止）」，關閉 TSCC_WASD，用實體手把或 Steam Input 玩該遊戲 |
| 登入後沒看到視窗 | 選了「登入時啟動…」時程式縮在系統匣，從圖示開啟 |
| 設定載入失敗 | 保留損壞的 JSON，還原 `.bak` 或修正錯誤後按「從磁碟重新載入」 |
| 選到不對的手把 | 自動偵測跟隨最後一支被按的手把；XInput 使用第一個可用的槽 |
| 映射意外停止 | 程式會自己重試；到「關於與說明」按「複製診斷資訊」，並附上「開啟日誌資料夾」裡當天的日誌回報 |
| 當機後遊戲看不到手把 | 重新開啟 TSCC_WASD 一次，它會還原自己改過的 HidHide 設定 |
| 想再看一次新手導覽 | 「關於與說明」→「重新顯示導覽」 |

更多：[疑難排解](TROUBLESHOOTING.md)。

## 解除安裝與還原被隱藏的手把

正常情況下，停止映射或關閉程式就會把手把還原。要完整移除：

1. 停止映射並關閉 TSCC_WASD。如果「登入 Windows 時」選的是「登入時啟動…」，先改選「不自動啟動」以移除開機項目。
2. 設定過「自動重新連接」的話，在「程式設定」頁的「自動重新連接」按「移除」（或以管理員身分刪除 `%ProgramFiles%\TSCC_WASD`，
   並在工作排程器刪除 `\TSCC_WASD\ReconnectControllers`）。
3. 刪除解壓出來的 TSCC_WASD 資料夾；要連同設定檔、設定與日誌一起刪除，再刪除 `%APPDATA%\TSCC_WASD`。
4. 視需要到「Windows 設定 → 應用程式 → 已安裝的應用程式」解除安裝 **ViGEmBus** 與 **HidHide**（DS4Windows 等工具可能也在使用）。

**手把不見了怎麼辦？** 先重新開啟 TSCC_WASD 一次，它會還原自己改過的設定。如果程式已經刪掉了，手把仍被隱藏：
開啟 **HidHide Configuration Client**（HidHide 的設定程式），到裝置清單取消勾選被隱藏的手把，並關閉隱藏功能。
先還原隱藏設定，再解除安裝 HidHide。

## 日誌與設定檔放在哪裡

全部在 `%APPDATA%\TSCC_WASD`（在檔案總管網址列貼上即可）：

| 檔案 | 內容 |
| --- | --- |
| `profiles.json`、`profiles.json.bak` | 設定檔與上一版備份 |
| `settings.json` | 程式設定 |
| `logs\` | 日誌，每個執行過的日期一個檔，保留最新的 7 個檔（不是 7 天） |
| `hidhide-restore.json` | 映射前的 HidHide 狀態，用來還原 |
| `ns2-calibration.json` | 已記住的 NS2 Pro 校準 |

「設定檔」頁 ⋯ 選單的「開啟設定資料夾」與「關於與說明 → 開啟日誌資料夾」都能直接開啟對應位置。
舊版（0.4.0 以前叫 YnyrWASD）的設定會在 0.4.1 之後自動搬移。

## 回報問題

1. 開啟「**關於與說明**」，按「**複製診斷資訊**」（版本、驅動程式、手把狀態）。
2. 按「**回報問題**」（或到 [GitHub Issues](https://github.com/ynyrworks/TSCC_WASD/issues)）新增問題，貼上診斷資訊，說明你做了什麼、預期什麼、實際發生什麼。
